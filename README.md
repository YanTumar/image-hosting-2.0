# 🖼️ Web Image Hosting Service

Простий, швидкий та надійний веб-сервіс для завантаження зображень, збереження їхніх метаданих у базі даних PostgreSQL та отримання прямих посилань.

## 🛠️ Технології

* **Backend:** Python 3.12 (вбудований HTTP-сервер, Pillow, psycopg2) 🐍
* **Database:** PostgreSQL 15 🗄️
* **Static Proxy:** Nginx ⚡
* **Containerization:** Docker & Docker Compose 🐳

## 📋 Основні маршрути API

| Метод  | Маршрут               | Опис                                                                                         |
| ------ | --------------------- | -------------------------------------------------------------------------------------------- |
| `GET`  | `/`                   | Головна сторінка сервісу 🌐                                                                  |
| `POST` | `/upload`             | Завантаження зображення (`.jpg`, `.jpeg`, `.png`, `.gif` до 5 МБ) та збереження метаданих 📤 |
| `GET`  | `/images/`            | Отримання та перегляд зображення 🖼️                                                         |
| `GET`  | `/images-list`        | Перегляд списку завантажених зображень із пагінацією (по 10 елементів) 📑                    |
| `GET`  | `/images-list?page=N` | Навігація по сторінках списку 📄                                                             |
| `DELETE`  | `/delete/`            | Видалення зображення та його метаданих 🗑️                                                   |

## 🗄️ Структура бази даних

Метадані завантажених файлів зберігаються в таблиці `images`:

| Поле            | Тип                  | Опис                                      |
| --------------- | -------------------- | ----------------------------------------- |
| `id`            | `SERIAL PRIMARY KEY` | Унікальний ідентифікатор 🔑               |
| `filename`      | `TEXT`               | Згенерована унікальна назва файлу 📄      |
| `original_name` | `TEXT`               | Оригінальна назва завантаженого файлу 🏷️ |
| `size`          | `INTEGER`            | Розмір файлу в байтах 📏                  |
| `upload_time`   | `TIMESTAMP`          | Дата та час завантаження 🕒               |
| `file_type`     | `TEXT`               | Формат файлу 🏷️                          |

## 🚀 Запуск проєкту

Для збірки та запуску всіх контейнерів виконайте команду:

```bash
docker compose up --build
```

## 💾 Резервне копіювання та відновлення бази даних

### 1. Створення резервної копії (Backup) 📦

Для створення резервної копії даних виконайте:

```bash
python backup.py
```

Скрипт автоматично згенерує `.sql` файл у папці `backups/`, наприклад:

```text
backups/backup_2026-09-26_150558.sql
```

### 2. Відновлення бази даних (Restore) 🔄

Щоб відновити стан бази даних з існуючого бекапу, виконайте:

```bash
docker exec -i image-hosting-20-db-1 psql -U postgres images_db < backups/НАЗВА_ВАШОГО_ФАЙЛУ.sql
```

> **📌 Примітка:** Замість `НАЗВА_ВАШОГО_ФАЙЛУ.sql` підставте реальне ім'я файлу з папки `backups/`.
>
> Наприклад:
>
> ```text
> backup_2026-09-26_150558.sql
> ```

## 📝 Логування

Усі важливі події, зокрема завантаження файлів, видалення, помилки та резервне копіювання, логуються у файл:

```text
./logs/app.log
```

📜 Лог-файл містить інформацію про роботу застосунку та допомагає відстежувати важливі події й помилки.
